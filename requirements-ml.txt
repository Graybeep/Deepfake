# GPU-inference image only.
# NOTE: no real EfficientNet weights are vendored in this repo yet. The default
# inference backend is `stub` (see src/df/inference/). Installing these packages
# does not by itself make the detector real -- see DECISIONS.md.
-r requirements.txt
torch==2.5.1
torchvision==0.20.1
# The DFDC-winner checkpoint's encoder is a timm model (tf_efficientnet_b7_ns),
# not a torchvision one. `measured: yes` 2026-08-29 by reading the checkpoint:
# its keys are module.encoder.{conv_stem,bn1,blocks.0-6,bn2,classifier} plus
# module.fc, and torchvision's EfficientNet uses features.*/classifier.* -- the
# two do not overlap at all. See src/df/inference/efficientnet.py.
timm==1.0.11
# A phone camera roll is HEIC by default and OpenCV has no HEIF codec at all
# (`measured: yes` 2026-08-31: its build lists JPEG, PNG, WEBP only). Without
# this, an iPhone upload decodes to nothing and the job reports "no faces" for a
# photo of a face. PIL will not open HEIC either until pillow_heif registers its
# opener, which is what the import in decode_image() is for.
pillow-heif==0.18.0
opencv-python-headless==4.10.0.84
librosa==0.10.2.post1
